# Оно тебе надо

Проектная работа первого спринта: вёрстка страницы аукциона вещей, в которые никто не верил.

Репозиторий: https://github.com/mariagubanova1712-hue/ono-tebe-nado-ad

## Что сделано

- семантическая разметка страницы: шапка, обложка, лоты, «Об аукционе», подвал;
- раскладка на grid и flexbox;
- оверлей на обложке и карточках;
- подключены шрифты Raleway.

## Структура

- `index.html` — страница;
- `styles/` — глобальные и собственные стили;
- `fonts/` — шрифты;
- `images/` — изображения.
